Comprehensive creative media library, design system kit, and brand asset directory for VessertID.

---

## 📂 Repository Directory Structure

```
assets/
│
├── README.md               # Detailed asset directory documentation
├── metadata.json           # Machine-readable asset index & metadata
│
├── fonts/                  # TrueType font family collection (20 fonts)
├── icons/                  # High-precision vector UI & brand iconography (41 SVGs)
├── colors/                 # Adobe Swatch Exchange (.ase) & Design Token Themes (.json)
├── sounds/                 # Backsound, SFX, ambient, loops, & voice-overs (.mp3)
├── videos/                 # Production b-roll, motion graphics, & transitions (.mp4)
├── backgrounds/            # Studio gradients, solids, patterns, & textures (.jpg)
├── overlays/               # Transparent overlay effects & framing (.png)
├── photos/                 # Commercial photographic library (.jpg)
├── illustrations/          # Flat, isometric, 3D, & vector artwork (.svg, .png, .ai)
├── stickers/               # Social stickers, animated GIFs, & WebP packs (.png, .gif, .webp)
├── mockups/                # Device and product presentation mockups (.png)
├── templates/              # Multi-channel social media, presentation, & email templates (.psd, .pptx, .html)
├── filters/                # 3D LUT grading (.cube) and Adobe/DaVinci presets (.xmp, .atn, .prfpset, etc.)
├── motion/                 # Production Lottie JSON animations, Rive runtimes, & motion loops
├── 3d/                     # Interactive 3D models, printable meshes, & studio HDRI (.glb, .obj, .stl, etc.)
├── ai/                     # Curated synthetic AI visual assets, audio textures, & prompt guides
├── brand/                  # Official VessertID logos, icons, animations, watermarks, & mascots
└── documents/              # Brand guidelines, style guides, SOPs, checklists, & manuals (.pdf, .md)
```
