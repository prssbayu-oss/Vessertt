# Checklist Desain Visual & Antarmuka VessertID

## Komposisi & Tata Letak
- [ ] Hierarki visual jelas (Heading -> Subheading -> Body Text -> Call to Action).
- [ ] Grid 8pt / 4pt diterapkan secara konsisten pada semua elemen spacing.
- [ ] White space cukup, tidak ada elemen yang bertumpuk atau terpotong.

## Warna & Kontras
- [ ] Menggunakan palet resmi (`VessertID-ColorPrimary`, `VessertID-ColorSecondary`, dll).
- [ ] Rasio kontras teks terhadap background minimal 4.5:1 (WCAG AA).
- [ ] Warna fungsional (Success, Warning, Error) tidak disalahgunakan untuk dekorasi semata.

## Tipografi
- [ ] Maksimal 2 keluarga font dalam satu komposisi.
- [ ] Line height proporsional (1.4 - 1.6x font size untuk body text).
- [ ] Kerning dan tracking disesuaikan untuk headline display.
