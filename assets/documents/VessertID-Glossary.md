# Glosarium Istilah Desain & Media VessertID

| Istilah | Definisi |
| :--- | :--- |
| **LUT (.cube)** | Look-Up Table: Transformasi matematika untuk grading warna video dan foto. |
| **ASE (.ase)** | Adobe Swatch Exchange: Format standar pertukaran palet warna digital Adobe. |
| **Lottie (.json)**| Format animasi vektor berbasis JSON ringan dari After Effects Bodymovin. |
| **GLB / glTF** | Format transmisi dan rendering 3D runtime standar web dan AR. |
| **Kerning** | Penyesuaian jarak spesifik antara sepasang huruf tertentu. |
| **Safe Zone** | Area kanvas yang dijamin tidak terpotong oleh antarmuka sistem aplikasi. |
| **B-Roll** | Footage pendukung yang disisipkan untuk memperkaya visual narasi utama. |
| **Design Token** | Variabel terpusat (warna, ukuran, font) yang menghubungkan desain dan kode. |
