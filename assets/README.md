# VessertID Digital Asset Management & Creative Media Library
**Version:** 2026.1.0  
**Organization:** VessertID Creative Studio & Agency  
**Licensing & Usage:** Proprietary / Authorized Client & Internal Production Only  

Welcome to the central repository of all official VessertID brand, creative, motion, audio, and visual design assets. This repository serves as the definitive Single Source of Truth (SSOT) for all digital campaigns, application interfaces, marketing materials, and physical brand merchandise.

---

## 📁 Directory Architecture

```
assets/
├── README.md               # Definitive asset registry documentation
├── metadata.json           # Comprehensive machine-readable asset catalog
├── fonts/                  # Curated typographic system (Display, Sans, Serif, Handwriting)
├── icons/                  # High-precision vector UI & brand iconography (SVG)
├── colors/                 # Adobe Swatch Exchange (.ase) & Design Token Themes (.json)
├── sounds/                 # Original backsound tracks, SFX, ambient, loops, and voice-overs (.mp3)
├── videos/                 # B-roll footage, motion graphics, intros, outros, & transitions (.mp4)
├── backgrounds/            # Studio gradients, solids, organic textures & patterns (.jpg)
├── overlays/               # Transparent particle, glow, bokeh, frame, and texture layers (.png)
├── photos/                 # Curated commercial photography, product, lifestyle, & editorial (.jpg)
├── illustrations/          # Flat, 3D render, isometric, character & infographic art (.svg, .png, .ai)
├── stickers/               # Social stickers, WhatsApp/Telegram packs, and animated badges (.png, .gif, .webp)
├── mockups/                # High-fidelity device, apparel, and packaging mockups (.png)
├── templates/              # Multi-channel social media, presentation, ads & email templates (.psd, .pptx, .html)
├── filters/                # 3D LUT grading (.cube) and Adobe/DaVinci editing presets (.xmp, .atn, .prfpset, etc.)
├── motion/                 # Production Lottie JSON animations, Rive runtimes, and motion loops
├── 3d/                     # Interactive 3D models, scenes, printable meshes & studio HDRI (.glb, .obj, .stl, etc.)
├── ai/                     # Curated synthetic AI visual assets, audio textures, and prompt guides
├── brand/                  # Official VessertID primary logos, icons, animations, watermarks & mascot
└── documents/              # Brand guidelines, style guides, SOPs, publish & licensing checklists (.pdf, .md)
```

---

## 🎨 Asset Naming Standard

All files strictly follow the **VessertID Unified Taxonomy**:
`VessertID-<Category><Descriptor><Variant?>.<ext>`

Examples:
- `VessertID-LogoPrimary.svg`
- `VessertID-ColorPrimary.ase`
- `VessertID-BacksoundLofiChill.mp3`
- `VessertID-TemplateStory1080x1920.psd`
- `VessertID-BrandGuideline2026.pdf`
